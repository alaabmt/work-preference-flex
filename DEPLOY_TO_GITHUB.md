# Deploy V17.4 to GitHub Pages

1. Unzip `work_preference_flex_V17_4_RICH_REPORT_GITHUB_READY.zip`.
2. Upload **the files inside the folder**, not the ZIP itself, to the root of your GitHub repository.
3. Confirm that `index.html`, `ar.html`, `en.html`, and `coach.html` are visible at the repository root.
4. In GitHub: **Settings → Pages → Build and deployment**.
5. Source: **Deploy from a branch**.
6. Branch: **main**. Folder: **/(root)**. Save if GitHub enables the button.
7. If the Pages source was already saved but the site was unpublished, commit this V17.4 upload to `main`; the new commit should trigger a new deployment.
8. After deployment, open the site in a private/incognito window once to avoid an old cached page.
