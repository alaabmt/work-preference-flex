# Work Preference & Flex — V17.5 Report Architecture

This folder is ready to upload to the **root of a GitHub Pages repository**. `index.html` is at the root.

## What this build contains

- Arabic participant assessment (`ar.html`) — full RTL.
- English participant assessment (`en.html`) — full LTR.
- A self-contained bilingual item bank embedded in both participant pages plus `item-bank.json` as the research/source copy.
- Coach dashboard (`coach.html`).
- Approved Arabic and English homepage infographics.
- A new rich participant report with ten structured sections/pages: profile overview, reading guide, three core orientation pages, profile combination, Working with Others, Environment Needs, contextual Flex, and development map.

## Scientific status

This is a **research pilot under validation**, not a diagnostic instrument and not intended for hiring, promotion, firing, or other high-stakes decisions. Core and environment 0–100 indicators are relative/ipsative within the participant's own responses. They are not percentiles or standardized scores. Working with Others is reported separately as a descriptive social-coordination indicator. Flex is interpreted from matched contextual response shifts and has no right/wrong score.

## GitHub Pages

Upload the contents of this folder directly to the repository root. Then use **Settings → Pages → Deploy from a branch → main → /(root)**.

## V17.5 participant-report revision
- Plain participant language: avoids orientation/tendency/prominent/less-relative phrasing.
- Core results keep numeric indices but remove /100 semantics and use a within-response reference marker.
- Page 6 retains a visual priority sequence while stating that it is not a fixed behavioral sequence.
- Social Coordination is reported as selected situations (e.g., 6/9), not as a 0–100 hero score.
- Environment Needs are rank-first; indices are secondary.
- Flex is factor-by-factor, with no shift-count headline and no visual reward for changing.
- Development experiment is no longer selected from the lowest core result.
