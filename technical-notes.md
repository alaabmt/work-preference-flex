# Technical Notes — V17.4 Rich Report

## Measurement architecture

Core work-regulation orientations remain: Understanding the Situation (U), Structuring the Work (S), and Starting Action (A). Working with Others (SOC) is a separate social-coordination focus. Environment Needs remain a separate layer. Contextual adaptation/Flex is represented through matched situation pairs rather than a correctness key.

## Numerical reporting

- Core 0–100 indicators are linearly rescaled average forced-choice ranks within the participant's profile. They remain ipsative/relative pilot indices.
- Social Coordination 0–100 is the percentage of the nine social-focus items on which the participant selected the direct social-coordination response. It is descriptive, not a teamwork skill score.
- Environment Need 0–100 indicators rescale each need's repeated forced-ranking position from the theoretical minimum to maximum within this section. They remain relative/ipsative and non-normative.
- Flex has no 0–100 score. The report shows each matched pair and whether the preferred response changed when one contextual parameter changed.

## Reporting safeguards

The report repeatedly distinguishes preference from ability, performance, environment need, and fixed behavior. Potential overuse is presented only as a hypothesis to test against real work examples; it is not inferred from score magnitude. Colors are participant-facing communication/navigation labels, not personality types.

## Print

The rich report uses A4 page-break rules and ten report sections. Browser PDF output may vary slightly with font rendering and print scale.
