# Technical Notes — V17

## Theoretical architecture
The central process backbone is Action Regulation Theory. It is used to explain goal-directed work regulation, not to claim that the theory defines personality colors or exactly three types.

The current **candidate core orientations** are:
1. Understanding the Situation — decision-relevant understanding and evaluation before commitment.
2. Structuring the Work — turning work into priorities, sequence, and executable structure.
3. Starting Action — moving from preparation to a workable step when conditions are sufficiently clear.

Working with Others is treated as a separate social-coordination focus. Contextual adaptation is read from changes in chosen orientations across matched situations. Environment needs remain a separate person–environment fit layer.

## Important exclusions
- Understanding is not intelligence, expertise, perfectionism, anxiety, or need for complete certainty.
- Structuring is not conscientiousness, dependability, obedience, orderliness, or performance.
- Starting Action is not impulsivity, risk-seeking, speed, or performance.
- Social Coordination is not extraversion, agreeableness, being nice, or needing consensus.
- Contextual adaptation is not a competence score.

## Preference scoring
Each of 30 triads contains one U, S, and A option. Participants rank them 3/2/1. The site reports a pilot relative index `((mean_rank - 1) / 2) * 100`. Because the design is ipsative, these are **within-profile relative indices only**. They are not percentiles, norms, or between-person trait estimates.

No pseudo-confidence interval is shown. A small descriptive co-leading rule is used only for communication and has no inferential interpretation.

## Social focus
Nine paired items contrast a task-direct response with a socially integrative response while keeping the underlying work-regulation process similar. The report shows the count of social-focus selections and process-specific counts. This is descriptive and requires validation.

## Environment needs
Nine 4-option ranking blocks retain six candidate conditions: clarity, information, autonomy, participation, priority/timing clarity, and change understanding. These are still pilot dimensions and should not be treated as an established factor structure.

## Flex/context
Four matched pairs vary reversibility, time pressure, interdependence, and ambiguity. Each condition offers U/S/A responses. The report shows whether the selected orientation changes across the pair. There is no right/wrong key and no total flexibility competence score.

## Research data
The site records participant code, administration, language, bank/blueprint version, deterministic item order, deterministic option order, raw ranks/choices, item latency, response changes, timestamps, profile fields, and research consent. JSON and long-form CSV export are available.
